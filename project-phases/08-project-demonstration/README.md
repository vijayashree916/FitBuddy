# Phase 8: Project Demonstration

## Demonstration flow
1. Start the server with `uvicorn app.main:app --reload`.
2. Open `http://127.0.0.1:8000`.
3. Submit user details and generate a plan.
4. Review the workout plan and nutrition tip.
5. Submit feedback and review the revised plan.
6. Open `/admin-login` and view the protected user dashboard.
7. Open `/docs` to demonstrate the JSON API documentation.
8. Open `/health` to demonstrate service health.

## Evidence to capture
- Initial user form.
- Generated plan.
- Revised plan after feedback.
- Admin dashboard.
- Passing test output.

## Output
A reproducible walkthrough for project review or presentation.
