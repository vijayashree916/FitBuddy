# Phase 1: Brainstorming & Ideation

## Idea
FitBuddy helps users create personalized workout plans and nutrition guidance with Gemini AI.

## Problem
Users need a simple way to receive an initial fitness plan and refine it from feedback without manually designing a weekly routine.

## Proposed solution
- Collect basic profile, goal, and intensity information.
- Generate a seven-day workout plan and nutrition tip.
- Allow feedback-based plan updates.
- Provide an admin view of registered users and plans.

## Output
A clear product concept and a prioritized list of user workflows.
