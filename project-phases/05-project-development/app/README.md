# App package

Application modules:
- `main.py` – FastAPI app setup
- `routes.py` – HTML and JSON route handlers
- `database.py` – SQLAlchemy models and persistence helpers
- `schemas.py` – Pydantic validation
- `gemini_client.py` – Google Gemini SDK client
- `gemini_generator.py` – 7-day workout generation
- `gemini_flash_generator.py` – nutrition/recovery tip
- `updated_plan.py` – feedback-based plan revision
- `config.py` – environment configuration
